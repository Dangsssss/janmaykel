# Bingo App (Vite + React + Tailwind)

## Quick start

1. Open a terminal in the project folder.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the dev server:
   ```bash
   npm run dev
   ```
4. Open the URL shown in the terminal (usually http://localhost:5173).

## Notes

- If you see warnings about Node engines, they are usually safe to ignore if installation succeeds.
- If Tailwind integration errors appear, ensure `postcss.config.js` and `tailwind.config.js` exist in the project root and `src/index.css` is imported from `src/main.jsx`.
